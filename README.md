# Writing Quality Evaluation

A structured workflow for reviewing grammar, clarity, organization, tone, instruction-following, and preservation of meaning.

## How to use
Open `data/writing_samples.csv` and use `docs/rubric.md` to review the synthetic samples. Add examples you have written or are permitted to use. For each response, provide scores, concrete evidence, a revision, and an explanation of edits.

No software dependencies are required. Scores and edits in the sample CSV are illustrative annotations, not an external benchmark.
